
# Ghi chú dự án

## Công việc thực hiện
1. Tạo repository trên GitHub Desktop.
2. Tạo các file dữ liệu.
3. Thực hiện commit.
4. Tạo branch để chỉnh sửa báo cáo.

## Ghi chú
Dự án sử dụng dữ liệu giả lập, không chứa thông tin cá nhân.

## Mục tiêu dự án
- Hiểu cách quản lý phiên bản bằng Git.
- Biết cách sử dụng GitHub Desktop.
- Theo dõi lịch sử chỉnh sửa của dự án.
- Thực hành làm việc với branch và đồng bộ dữ liệu.

## Nguồn dữ liệu
Dữ liệu trong dự án được tự tạo và mô phỏng
nhằm phục vụ mục đích học tập.
Không sử dụng dữ liệu cá nhân hoặc dữ liệu nhạy cảm.
